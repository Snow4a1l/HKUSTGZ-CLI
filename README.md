# hkustgz-cli

香港科技大学（广州）同学日常助手。向AI直接提问：“最近DDL，帮我安排时间”“哪里补办校园卡”“打印机驱动在哪”“应用统计这门课怎么样”“给我本科学生手册/校历”。

当前是 **0.2.0-alpha.1候选版**，官方项目入口：[https://github.com/Snow4a1l/HKUSTGZ-CLI](https://github.com/Snow4a1l/HKUSTGZ-CLI)。给AI一句话：“安装 hkustgz-cli，项目：https://github.com/Snow4a1l/HKUSTGZ-CLI”。只说名称取决于AI能否正确检索到此仓库；首次建议附上链接。证据和缺口见[验收记录](docs/V1_ACCEPTANCE.md)与[当前状态](docs/STATUS.md)。

已完成安装副本的一轮真实刷新、今日课表/近期DDL查询和安排草案验证。此前连接关闭的尝试明确标为partial，恢复后新建批次完成；没有用旧批次补齐。覆盖仍限于已发现课程及首100项，详见下文。公开仓库不包含账号的课程、成绩、DDL、采集批次或其他私人证据。

## 第一次使用

1. 把上述仓库链接交给AI，说“阅读INSTALL.md，安装hkustgz-cli”。AI执行安装器并读取安装后的技能；你无需填课程ID、复制快照或修改代码。
2. 问日常问题。个人课表/DDL查询会打开SISN和Canvas；出现学校登录页时，你在网页正常登录，完成后告诉AI“已登录”。不要在聊天发送密码或验证码。
3. 检查答案包含覆盖课程、采集时间、限制和官方链接。办事/文件查询会注明索引核实日期，不冒充实时读取。

已验证环境：Windows、Node.js >=20、支持本地命令及in-app Browser的Codex；无第三方运行依赖。其他AI宿主尚未验证Browser适配，仅有文字聊天的AI不能采集个人数据。安装、更新、卸载见[INSTALL.md](INSTALL.md)。

## 日常使用与普通用户验收

| 对AI说 | 应看到什么 | 怎样核对 |
| --- | --- | --- |
| 刷新最近两周DDL，帮我安排时间 | 自动发现当学期课程，刷新SISN今日课表与Canvas任务；课程、日期、链接和更新时间齐全。安排默认每天19:00–21:00、每项估计90分钟，列排不下/无日期/逾期项目 | 与All Courses和作业页面比较；告诉AI真实空闲时间。外部答题、线下展示和提醒需确认实际完成情况 |
| 校园卡丢了，哪里补办 | 事项链接、费用、领卡说明；保留中英文办理时长冲突，不提交申请 | 打开官方事项，核对卡类型、费用和通知，别误选庆盛门禁卡 |
| 学校打印机驱动在哪里 | ITD官方下载中心、Windows/Mac指南及正文页码；说明下载需学校登录 | 打开入口选择适合系统的驱动；本项目不代装驱动 |
| 应用统计这门课怎么样 | 2026–27 Fall官方内容、3学分和先修要求；明确缺少学生评价与给分证据 | 在PCC按学期和代码核对。未收录课程提供官网入口，不编难度 |
| 给我本科学生手册和校历 | OSA当前链接的2025本科入学指南、2026–27广州校历；版本、原文和已读页码明确 | 打开文件核对年份；2025指南不冒充2026版或正式学业规章 |

Canvas仅覆盖已列出的当学期学生课程。会核对All Courses表格和网页作业，发现可见作业遗漏就报错；Browser无法读取官方分页Link头，仍不保证全分页/全账号完整。未发布课程、其他平台及通知里仅文字描述的DDL可能遗漏。SISN只保证捕获日期周，未自动核对临时停调课，不生成ICS。

时间安排是草案：工时与空闲时段是假设，未来课表和私人日程尚未完整获取；会避开已捕获的具体课程时间、任务开放/关闭时间与DDL。不写入外部日历。

## 常见失败与恢复

| 情况 | 你做什么 | AI应怎样处理 |
| --- | --- | --- |
| 需要登录 | 在提示的学校Browser页登录后说“已登录” | 检查页面并新建刷新，不索取认证材料 |
| REFRESH_REQUIRED | 说“重新刷新” | 超过60分钟或跨上海日期必须采集，旧数据不能冒充实时 |
| CAPTURE_IN_PROGRESS或聊天中断 | 说“继续刷新” | 读取状态继续pending步骤，不重填课程 |
| 来源失败、权限或页面布局变化 | 查看提示的页面，必要时登录 | 说明哪个来源未知及覆盖缺口，不把失败当作没有课/作业；修复后新建尝试 |
| 搜索不到 | 给出具体名称 | 未收录不表示不存在；补查官方来源，不编造结果 |
| 同名安装目录冲突 | 保留目录并把报错交给AI | 拒绝覆盖非本安装器管理的目录，不擅自删除 |

完整刷新在当前Browser环境中可能需要十多分钟，耗时随课程数和浏览器响应变化，AI会分阶段报告。刷新完成后一小时内普通查询可复用该批次；用户明确要求刷新时仍重新采集。私人数据默认在各自 `~/.hkustgz-cli`，与安装目录分离；更新保留状态。共用操作系统账户不提供账号隔离，可用绝对路径环境变量HKUSTGZ_HOME指定独立目录。不要上传私人状态。

## 开发命令

```powershell
node scripts/install.mjs
node src/cli.js setup
node src/cli.js doctor --offline
node src/cli.js daily status
node src/cli.js daily agenda --days 14
node src/cli.js daily plan --minutes 60 --window 18:00-22:00
node src/cli.js service search "哪里能补办校园卡"
node src/cli.js document search "打印机驱动"
node src/cli.js course explain "应用统计这门课怎么样"
node src/cli.js help
npm test
```

安装后以安装器返回的cli绝对路径为入口，可从任意工作目录运行。全部命令输出单行JSON。退出码0成功、2参数、3认证/权限、4格式/覆盖/过期/未实现、5限流，其余1。查询命令读取本地批次，采集由技能驱动Browser；auth status仅报告能力，不证明登录有效。协议见[DAILY.md](docs/DAILY.md)。

进阶能力保留：[教务与成绩快照](docs/ACADEMICS.md)、[Canvas只读接口](docs/CANVAS.md)、[概览快照](docs/BROWSER_COURSES.md)。这些功能未全部自动刷新。当前13项服务、7份文件摘要、11/266门课程；部分事项只有标题，不是完整办事/文件库或学生评课库。专业要求覆盖两个入学年份，AI培养要求已有官方PDF摘要。

完整清单保留在[HANDOFF.md](HANDOFF.md)。图书馆、缴费、ClassViva暂缓；场馆、完整目录、排名/修读进度、毕业审核和考试安排尚未完成。业务申请、付款、预约、取消、选退课或答题提交均需具体授权。

分发方式为GitHub源码安装；当前没有npm发布或GitHub Release，package保持private、UNLICENSED。运行代码独立实现；参考目录与个人验证记录不入仓库和包。许可证尚未指定。
