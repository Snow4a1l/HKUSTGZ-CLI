# hkustgz-cli

**用自然语言查港科广的课、DDL、办事入口和学校文件。**

hkustgz-cli 是面向香港科技大学（广州）同学的 CLI 与 AI Skill。你负责提问，AI 调用工具查数据，再把结果整理成带来源、更新时间和覆盖范围的回答。

当前版本：`0.2.0-alpha.1` · 候选版 · Node.js 20+ · 无第三方运行依赖

[快速开始](#快速开始) · [可以问什么](#可以问什么) · [功能与覆盖范围](#功能与覆盖范围) · [失败时怎么办](#失败时怎么办) · [安装说明](INSTALL.md) · [验证与未完成项](docs/STATUS.md)

> 核心流程已经过真实学校登录会话验证，也验证过从 GitHub 重新克隆后的独立安装。当前支持范围仍有限，不代表所有模块、所有课程或所有 AI 环境都已完成。

## 快速开始

把下面这一句话发给你的 AI：

```text
请安装 https://github.com/Snow4a1l/HKUSTGZ-CLI 中的 hkustgz-cli，阅读 INSTALL.md，完成安装和自检。
```

之后直接问：

```text
刷新最近两周的 DDL，帮我安排一下时间。
```

项目的目标使用方式是“告诉 AI 安装 hkustgz-cli”。首次建议附上仓库链接，确保 AI 找到的是这个项目。

### 第一次使用会发生什么

1. **AI 安装工具。** 检查 Node.js，读取仓库安装说明，将包含运行代码的 Skill 安装到本机，并执行自检。
2. **你在学校网页登录。** 查询个人课表或 DDL 时，AI 使用 Browser 打开 SISN 和 Canvas。如果出现登录页，你在网页里正常完成密码和 MFA，之后告诉 AI“已登录”。
3. **AI 刷新并回答。** 工具自动寻找标签页、发现课程和采集任务；你无需填写课程 ID、复制网页快照或修改代码。

补卡、驱动和文件入口等随包索引查询可以先用；个人课表和 DDL 需要有效的学校登录。不要把密码、验证码、Cookie 或令牌发到聊天。

### 目前适合什么环境

| 环境 | 当前情况 |
| --- | --- |
| Windows + Node.js 20+ | 已验证安装与运行 |
| 支持本地命令和 in-app Browser 的 Codex | 已验证核心日常流程 |
| 其他能够执行 Node.js 的 AI | 可使用 CLI；个人数据刷新还需要适配其受支持的浏览器 |
| 只有文字聊天、无法执行命令的 AI | 无法自行完成本机安装与采集 |
| 其他操作系统与其他学生的新账号登录 | 尚未完成真实验收 |

当前分发方式是 **GitHub 源码安装**，还没有 npm 发布或 GitHub Release。不要把来源不明的同名 npm 包当作本项目。

自动安装器目前写入 Codex 的技能目录。Claude 等其他宿主的技能安装和浏览器适配尚未完成，不能把“能运行 Node.js”当作“已支持全部功能”。

## 可以问什么

### 最近有什么 DDL，怎么安排时间

```text
今天有什么课？最近两周有哪些 DDL？
```

```text
刷新 DDL，按截止时间排序。我每天晚上 20:00–22:00 有空，先按每项 60 分钟给我一份草案。
```

正常回答应列出课程、任务名称、截止时间、原链接和采集时间，并说明实际查了哪些课程、有没有失败或未核对的部分。没有注明日期的任务会单列，不会直接丢弃。

时间安排是**可修改的草案**。默认每天 `19:00–21:00`、每项估计 `90 分钟`；你可以提供自己的空闲时段和估时。工具会避开已捕获的具体课程时间、已排工作块、任务开放/关闭时间和截止时间，并列出排不下的任务。

工时不是官方数据，未来课表和私人日程也没有完整获取。外部答题、线下展示和仅作提醒的项目，需要你确认实际是否完成。工具不会替你写入外部日历。

### 校园卡丢了，去哪里补办

```text
哪里能补办校园卡？需要什么材料，大概多少钱？
```

返回已核实的学生补卡事项、办理入口、来源日期和已知说明。办理时长的中英文说明存在冲突时会保留冲突，不擅自选一个答案；实际费用、卡类型及通知以办理页面为准。

查询只提供信息和入口，不提交申请或付款。

### 学校打印机驱动在哪里

```text
学校打印机驱动在哪里？我用 Windows。
```

返回 ITD 官方下载中心和对应指南，说明登录要求及已读正文页码。也可以问 Mac 或 Linux 的指南入口。项目不会自动下载并运行打印机驱动安装程序。

### 一门课怎么样，有什么先修要求

```text
应用统计这门课怎么样？讲什么，有哪些先修要求？
```

根据当前已收录的官方课程说明、学分、先修条件和专业要求介绍课程，并注明学期。**没有学生评价、给分分布或实际工作量证据时，不编“水不水”“好不好拿分”。**

课程目录目前只收录一部分。未找到时会说明未收录，并提供官方 PCC 入口；不能据此判断学校没有这门课。

### 找本科手册、校历或专业要求

```text
给我本科学生手册和广州校区的校历，注明是哪一年的。
```

```text
按 2026–27 入学要求，解释一下 AI 专业的学分要求。
```

文件查询提供官方原文链接、适用版本、来源日期和已读章节或页码。当前 OSA 入口链接的是 **2025 本科入学指南**，校历收录 **2026–27 广州校历**；不会把旧指南称作新版，或把指南当作正式学业规章。

专业要求需要明确入学年份。AI 培养要求已有官方 PDF 摘要，但个人修读进度对照和毕业审核尚未完成。

## 功能与覆盖范围

| 能力 | 当前可用内容 | 主要边界 |
| --- | --- | --- |
| 今日课表 | Browser 刷新 SISN 实际日期周，展开当天卡片 | 只保证捕获日期周；临时调停课未独立协调，无 ICS |
| Canvas DDL | All Courses 发现当学期学生课程，逐课采集，汇总近期、逾期和无日期任务 | 每课接口首 100 项；网页交叉核对不能证明全分页完整 |
| 时间安排 | 可调整空闲时段和估时的安排草案 | 实际工时、外部完成状态及未来私人安排需确认 |
| 办事入口 | 13 项服务或导航，包含补卡详情和打印驱动入口 | 部分 Portal 事项仍只有标题或导航 |
| 学校文件 | 7 份官方摘要或入口，部分带已读 PDF 页码 | 不是全校文件全文库，不保证最新同名文件都已收录 |
| 课程介绍 | 2026–27 Fall 目录中的 11/266 门课程，部分有完整说明 | 无学生评课数据库，不能编体验或给分结论 |
| 专业要求 | 两个入学年份的目录，以及 AI 培养要求摘要 | 其他专业附件未全部读取，不输出毕业资格结论 |
| 成绩 | SISN 离线成绩快照和官方统计解析 | 尚未自动刷新，不猜排名或重算重修规则 |
| 进阶接口 | 单课程 Canvas 快照及已有授权令牌的只读 HTTP 路径 | HTTP 令牌路径只有离线测试，不是日常使用的前置条件 |

能力分为“已实现”“离线验证”“真实系统验证”，不能互相替代。详细证据在[当前状态](docs/STATUS.md)，普通用户验收结果在[验收记录](docs/V1_ACCEPTANCE.md)。

## 数据从哪里来，多久更新

**个人日程：** AI 通过受支持的 Browser 使用正常学校登录采集 SISN 和 Canvas，再由 CLI 校验并查询本机批次。CLI 查询命令本身不会登录网站；AI 按已安装的 Skill 驱动 Browser。

**办事、文件与课程资料：** 当前主要读取随包的已核实官方索引。回答应注明来源与核实日期，不能把索引查询说成刚刚联网检查。索引检索主要使用标题、摘要和中英文别名，不是全校语义搜索。

- 默认以 `Asia/Shanghai` 判断日期；超过 `60 分钟` 或跨上海日期，个人日程必须重新刷新。
- 新刷新失败时，明确报告失败或部分结果，不回退到旧成功批次冒充新数据。
- Canvas 记录的是已发现当学期课程及所捕获的任务；未发布课程、其他平台和通知正文中的 DDL 可能遗漏。
- 网页可见作业与接口结果会交叉核对。网页不可用时明确标记未核对；Browser 无法取得官方分页 Link 头，所以仍不保证全账号、全分页完整。
- Canvas 的“未提交”不等于外部工具或线下活动实际未完成。

完整刷新在当前 Browser 环境中可能需要十多分钟，随课程数和浏览器响应变化，AI 应分阶段报告。完成后一小时内普通查询可以复用同一批次；你明确要求刷新时，仍会重新采集。

采集、续接和字段语义见[日常数据协议](docs/DAILY.md)。

## 失败时怎么办

| 你遇到的情况 | 你可以对 AI 说 | 应有的处理 |
| --- | --- | --- |
| 学校网页要求登录 | “我已在网页登录，继续。” | 检查页面后开始新尝试，不索取认证材料 |
| 数据过期：`REFRESH_REQUIRED` | “重新刷新。” | 重新采集，不能用旧数据冒充实时 |
| 中断或 `CAPTURE_IN_PROGRESS` | “继续刚才的刷新。” | 读取保存的进度，继续尚未完成的阶段 |
| 来源失败或显示部分结果 | “说明哪些来源没查到，继续能查的部分。” | 失败与未尝试分别标记，不解释为没有课或没有作业 |
| 网络恢复了 | “开始一次新刷新。” | 使用新批次，不手工拼入旧结果 |
| 服务、文件或课程搜不到 | “帮我查官方来源，说明当前索引缺什么。” | 未收录不表示不存在，不编造链接或结论 |
| 安装目录冲突 | “保留原目录，检查安装报错。” | 拒绝覆盖非本安装器管理的同名目录，不擅自删除 |

如果按本 README 操作遇到卡点，应作为项目问题修复。可以在 [Issues](https://github.com/Snow4a1l/HKUSTGZ-CLI/issues) 描述命令、错误码和预期结果；不要上传个人快照、成绩、身份区截图或认证材料。

### AI 说找不到仓库，或者猜它是私有的

这是[公开仓库](https://github.com/Snow4a1l/HKUSTGZ-CLI)，读取源码不需要 GitHub 登录。AI 没有打开链接、搜索不到结果或连接工具报错，都不足以证明仓库是私有的；原因需要根据实际报错判断。

可以让 AI 先直接读取较简单的[安装说明原文](https://raw.githubusercontent.com/Snow4a1l/HKUSTGZ-CLI/main/INSTALL.md)：

```text
先直接读取 https://raw.githubusercontent.com/Snow4a1l/HKUSTGZ-CLI/main/INSTALL.md ，不要只靠搜索结果判断仓库是否存在。如果仍然无法访问，请说明你尝试的地址和具体错误；如果可以读取，再检查当前环境是否具备安装与运行条件。
```

如果当前 AI 的环境无法访问 GitHub 或原文域名，需要解决它的联网能力，或自行从 GitHub 下载源码供它读取。不要因为搜索失败就修改仓库可见性。

### Claude 可以使用吗

需要分开看三件事：

1. **读取说明：** 需要它的联网工具能够访问仓库或上述原文地址。
2. **运行 CLI：** 需要它能够执行本地命令，并有 Node.js 20+。
3. **自动刷新个人数据：** 还需要兼容的 Skill 安装和受支持的 Browser，当前只在 Codex 环境完成验证。

因此，当前版本不能承诺把仓库链接交给任意 Claude 环境，就会自动获得全部功能。让 AI 明确报告它具备哪些能力、缺少哪个环节。

## 本机数据与隐私

| 位置 | 用途 |
| --- | --- |
| `~/.codex/skills/hkustgz-cli` | 默认 Skill 安装目录，内含运行代码；设置 CODEX_HOME 时跟随其位置 |
| `~/.hkustgz-cli` | 默认私人状态目录，保存本机课表和任务批次 |
| `HKUSTGZ_HOME` | 可指定另一个绝对路径作为私人状态目录 |

更新安装不会覆盖私人状态。共用操作系统账户不提供账号隔离；不同同学不要轮流共用同一状态目录。

公开仓库和分发包只包含代码、官方来源索引、合成测试及匿名验证结论，不包含个人课表、成绩、DDL、采集批次或认证材料。Browser 采集不导出 Cookie 或令牌；原始接口响应在保存前会做白名单提取。

卸载时只移除安装器返回的 Skill 目录，个人状态默认保留；如需删除私人数据，应另行明确指定。安装器只更新自己管理的安装，不覆盖其他同名目录。

## 手动安装与命令参考

日常使用不要求你手动执行这些命令；以下供维护者或希望直接使用 CLI 的同学参考。

首次下载源码并安装：

```powershell
git clone https://github.com/Snow4a1l/HKUSTGZ-CLI.git hkustgz-cli
cd hkustgz-cli
node --version
node scripts/install.mjs
```

已有源码副本时，在该副本目录运行安装器即可。Node.js 必须为 20 或以上；安装器本身不下载 Node.js。安装器返回 Skill 与 CLI 的绝对路径，安装后的 CLI 可从任意工作目录运行。

在源码根目录查询：

```powershell
node src/cli.js setup
node src/cli.js doctor --offline
node src/cli.js daily status
node src/cli.js daily agenda --days 14
node src/cli.js daily plan --minutes 60 --window 20:00-22:00
node src/cli.js service search "哪里能补办校园卡"
node src/cli.js document search "打印机驱动"
node src/cli.js course explain "应用统计这门课怎么样"
node src/cli.js program show beng-ai --intake 2026-27
node src/cli.js help
```

`daily agenda` 和 `daily plan` 需要先由 AI/Browser 完成有效采集；独立运行 CLI 不会自动接管浏览器。`doctor --offline` 检查本地能力，`auth status` 只报告适配能力，两者均不能证明当前学校登录有效。

所有命令输出单行 JSON。成功包含 `ok: true`，失败包含 `ok: false` 和错误码；`--json` 可用于兼容。退出码：0 成功、2 参数、3 认证/权限、4 格式/覆盖/过期/未实现、5 限流，其余为 1。

测试与本地打包：

```powershell
npm test
npm pack
```

更新时，让 AI 从同一仓库取得新版、重新运行安装器，再读取新 Skill 和刷新数据。更详细的安装、更新与卸载说明见 [INSTALL.md](INSTALL.md)。
