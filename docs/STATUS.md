# 当前实施与验证状态

版本0.2.0-alpha.1，核实日期2026-10-30。仓库：https://github.com/Snow4a1l/HKUSTGZ-CLI 。当前为候选版，不能宣称全部模块、所有AI宿主或其他学生账号均已验收。

## 已实现

- 自带runtime的技能安装器、setup、独立用户状态目录、受管理更新及冲突保护。支持从任意cwd运行和搬移安装目录；更新不覆盖私人状态，新安装不带维护者数据。
- Browser工作流configure/start/step自行查找标签和课程，不依赖旧聊天或固定课程ID。daily agenda检查最老来源、上海跨日、新旧批次隔离与缺失来源；中断可继续。
- Canvas从All Courses可见表格发现当学期Student记录，不依赖新旧仪表盘或收藏课程；逐课GET首100项，与Assignments网页可见ID交叉检查。缺失即失败，网页不可用则明确unavailable。单来源失败可继续其余来源，整站故障可finishPartial；失败与未尝试分开记录，不回退旧数据。
- daily plan按DDL估时排块，避开已知课程、开放/关闭时间和已有工作块，保留未排/无日期/逾期项目；明示工时和空闲假设，不写日历。
- 服务与文件原问法检索、course explain。服务13项、文件7份摘要、课程11/266；不是完整文件库或评课数据库。专业目录覆盖两个入学年份，AI官方培养要求有逐页来源。

本地全套35项测试通过，含解析、批次/过期、HTTP合成分页/认证错误、真实问法召回、规划约束、安装搬移/更新/隔离/冲突及partial结束。Skill官方校验器通过。

实际打包、检查归档、干净解压后全套测试与独立安装通过；从不同cwd运行setup、doctor和daily status成功，新状态没有维护者私人数据。包内运行代码与已验证副本一致。
